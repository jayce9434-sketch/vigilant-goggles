# THE HOLLOW BELOW — Attempt 2 Hard Fix

A self-contained browser horror game built for GitHub Pages.

## Run
Open `index.html`, or host this folder on GitHub Pages / any static server.

## Controls
- PC: WASD, mouse, Shift, E, F, J, Esc
- iPad/mobile: left stick, drag right side to look, RUN, USE, LIGHT, J

## Hard-fix changes
- iOS selection / callout / double-tap zoom / browser gesture suppression
- proper grid DDA raycasting and mobile 30 FPS frame budget
- no coplanar 3D geometry, eliminating the previous Z-fighting-style artifacts
- generated concrete/tile/metal/mold/flesh textures and generated prop art
- articulated monster body with independently animated head, neck, torso, arms, forearms, claws, thighs and shins
- corner-peek scare system plus psychological scripted scares
- 8 floors with escalating objectives, notes, hiding, chase AI and persistent checkpoints
- four synchronized industrial/metal chase layers
